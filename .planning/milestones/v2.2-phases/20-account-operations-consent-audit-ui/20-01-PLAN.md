<objective>
Lift the porteiro-only restriction in the administrative password reset handler and wire real SMTP delivery,
so a TenantAdmin can reset any of their own admins or porteiros (ACCNT-01) with the temporary password dispatched
by email and a delivery-state returned instead of plaintext (ACCNT-02). Add a tenant-scoped staff-list endpoint
that a TenantAdmin can reach to pick a reset target.

Purpose: The reset endpoint shipped in Phase 18 but (a) restricts TenantAdmin to Porteiro accounts only and
(b) returns the temp password inline and hardcodes deliveryState "Sent" without ever calling IEmailSender.
Both gaps must close server-side (never in the browser) before any TenantAdmin reset UI can exist.

Output: A reset handler that role-lifts admin+porteiro and SMTP-dispatches, a new ResetUserPasswordResponse shape
(no plaintext), a GET /api/v1/security/staff endpoint, and updated unit + integration tests.
</objective>
