<objective>
Add the TenantAdmin-reachable password reset surface to the condominium management UI: load the tenant's staff list
via GET /api/v1/security/staff (Plan 20-01), render admins + porteiros with a per-row reset action, and show delivery
feedback from the new reset response. This is the UI caller behind a TenantAdmin-reachable guard required by ACCNT-01,
with ACCNT-02 delivery feedback replacing the old platform-admin copy-to-clipboard modal.

Purpose: The reset endpoint and staff-list endpoint are now server-side (Plan 20-01). The administration page currently has
no reset surface; the only reset UI is platform-admin-gated (condominiums.page.ts). Wire the TenantAdmin surface on the
existing administration page (already under an authenticated shell with tenant context) so syndics can operate their own staff.

Output: Updated Angular services and an administration page that lists staff and triggers resets with delivery feedback.
</objective>
