<objective>
Surface device health so hardware problems are visible before they become gatehouse workflow failures. After 26 ships, simulated heartbeats update a `device_heartbeats` table with per-device status (`online`/`offline`/`degraded`), a `/devices` dashboard page (TenantAdmin + Porteiro) shows per-device health with 30s polling, and the gatehouse-panel renders an offline-alert toast on online→offline transitions. Recovery is automatic — when heartbeats resume, status returns to online without operator intervention.

Purpose: DOOR-12 + DOOR-13 + DOOR-14. The reason 26 ships after 25: Phase 25's `IngestDeviceEventHandler` already routes events; Phase 26 teaches the heartbeat branch to delegate to a new `IngestHeartbeatHandler` and replaces the previous 400. The reason 26 ships AFTER 24 (admin) and AFTER 25 (events): health is read-only on top of devices registered in 24 and events ingested in 25; no new write paths. The reason 26 ships a new `/devices` route (separate from `/administration`): hardware observability is operationally distinct from hardware configuration.

Output: 1 new SQL migration pair, ~10 new C# files (entity, enum, repository, handler, validator, DTO, endpoints, DI updates), 1 modification to Phase 25's `IngestDeviceEventHandler` (Heartbeat branch reroute), 5 new Angular files (page + service + 2 specs + index update), 2 modifications to existing Angular files (gatehouse-panel + sidebar), 2 small design-system extensions (`warning` tone on badge + toast), 1 OpenAPI regeneration, 3 new integration tests + 3 new visual/a11y specs.

</objective>

      ```
      1. if (tenant.DoorIntegrationEnabled == false) return TenantFlagOff;
      2. var device = deviceRepo.GetByIdAsync(tenantId, deviceId);
         if (device == null || device.RemovedAtUtc != null || !device.IsActive) return DeviceInactive;
      3. var existing = heartbeatRepo.GetAsync(tenantId, deviceId);
      4. var thresholds = existing?.OfflineAfterSeconds ?? 60; var errorThresholdPct = existing?.ErrorRateThresholdPercent ?? 10.00m;
      5. var gap = now - (existing?.LastHeartbeatAtUtc ?? now);
      6. var errorRate = (decimal)payload.ErrorCount / Math.Max(payload.EventsSinceLastSuccess, 1) * 100m;
      7. var newStatus =
             gap > TimeSpan.FromSeconds(thresholds) ? DeviceStatus.Offline
           : errorRate > errorThresholdPct ? DeviceStatus.Degraded
           : DeviceStatus.Online;
      8. var heartbeat = existing is null
             ? new DeviceHeartbeat(DeviceId, TenantId, now, newStatus, payload.ErrorCount, payload.EventsSinceLastSuccess, thresholds, errorThresholdPct, now)
             : existing.Update(now, newStatus, payload.ErrorCount, payload.EventsSinceLastSuccess);
      9. heartbeatRepo.UpsertAsync(heartbeat);
      10. logger.LogInformation("device.heartbeat.{Status} {TenantId} {DeviceId} {ErrorCount}/{Events} = {ErrorRate}%", newStatus, tenantId, deviceId, payload.ErrorCount, payload.EventsSinceLastSuccess, errorRate);
      11. return IngestHeartbeatResult.Ok(newStatus);
      ```
