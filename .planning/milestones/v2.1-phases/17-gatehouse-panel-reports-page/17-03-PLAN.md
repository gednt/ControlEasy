# Plan 17-03: Reports Page, Unified Ledger Server-Side Filtering & CSV Export

## Objective
Deliver the complete `/reports` page within the authenticated application shell, resolving the dead dashboard handover link. Provide intuitive date range selection (Today, 7 days, 30 days, Custom), summary cards for daily visit counts and residents per apartment, the unified history ledger with server-side search and filtering (date, status, subject, destination, origin), and millisecond-precision CSV export.

## Requirements Covered
- **PANEL-04**: `/reports` page with date ranges (Today/7d/30d/custom), visit counts by day, residents per apartment, unified history table, and CSV export (millisecond-precision pattern); consumes the generated OpenAPI report clients; the dashboard "Review reports and history" link resolves to it (dead-link fix)
- **PANEL-05**: Ledger filtering and server-side search on the unified stream (date, status, subject, destination, origin)

## Tasks

### Task 1: Route Registration & Dashboard Handover Link Resolution
- Location: `src/Web/ControlEasyReborn.Web/src/app/app.routes.ts`
- Add route:
  ```ts
  {
    path: 'reports',
    canActivate: [authGuard],
    data: { breadcrumb: 'Reports & History' },
    loadComponent: () => import('./features/reports/reports.page').then((m) => m.ReportsPage),
  }
  ```
- Verify `dashboard.page.ts` link `<a routerLink="/reports" class="handover-link">Review reports and history →</a>` navigates to `/reports`.

### Task 2: Reports Page Component & Layout
- Location: `src/Web/ControlEasyReborn.Web/src/app/features/reports/reports.page.ts`
- Implement modern Shift Ledger design system styling:
  - Header with title "Reports & History", date range selector, refresh button, CSV export button.
  - **Date Range Presets**:
    - "Today" (current date 00:00:00 to 23:59:59 tenant-local boundary)
    - "7 Days" (last 7 days to today)
    - "30 Days" (last 30 days to today)
    - "Custom" (date inputs for start and end date)
  - **Summary Cards**:
    - Visit counts by day bar/table breakdown (consuming `ReportsService.apiV1ReportsVisitCountsByDayGet`)
    - Residents per apartment breakdown (consuming `ReportsService.apiV1ReportsResidentsPerApartmentGet`)

### Task 3: Unified History Table with Server-Side Filtering (PANEL-05)
- Consume `ReportsService.apiV1ReportsHistoryGet$Response` to access both `HistoryRowResponse[]` body and `X-Total-Count` header.
- Filter toolbar:
  - Text search `q` (visitor name, document, or destination) with debounce.
  - Status / Native State filter dropdown (All, CheckedIn, Pending, CheckedOut, Cancelled, Recorded, Refused).
  - Subject Type filter (All, Resident, Visitor, ServiceProvider, Vehicle).
  - Carrier Code filter (input or selector).
- Table columns:
  - Occurred At (formatted date + time)
  - Kind (badge: `visit`, `security-event`, `package-drop`, `refused-scan`, `legacy-entry-log`)
  - Subject (Name, Document, Type)
  - Destination (Apartment or Gatehouse)
  - State (Badge with native decision/state)
  - Details (Purpose, Package description, Carrier code, Failure code)
- Server-side pagination controls (Page, PageSize, Total records).

### Task 4: Millisecond-Precision CSV Export
- Export button triggers CSV generation from the current filter query:
  - Header: `OccurredAt,Kind,Source,NativeState,SubjectType,SubjectName,SubjectDocument,Destination,Purpose,PackageDescription,PackageCarrierCode`
  - Timestamp column formatted with millisecond precision: `yyyy-MM-dd HH:mm:ss.fff`
  - Proper CSV field escaping for quotes and commas.
  - Download filename pattern: `reports-history-YYYY-MM-DDTHH-mm-ss.fffZ.csv` or `reports-history-YYYY-MM-DD.csv`.
