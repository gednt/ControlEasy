# Plan 18-03: Self-Service Forgot Password & Frontend Flows

## Objective
Implement enumeration-safe self-service password recovery for administrators and frontend reset workflows:
1. `POST /api/v1/security/auth/forgot-password`:
   - Restricted to admin roles (`TenantAdmin`, `PlatformAdmin`).
   - Constant-time decoy verification on email miss to prevent timing attacks.
   - Uniform response body: `{ "message": "If an account matches that email, instructions have been sent." }` regardless of whether the account exists or is active.
   - Named ASP.NET Core 8 rate-limiting policy partitioned on normalized email + durable account counter.
   - Email dispatch with temporary password via `IEmailSender`.
   - Idempotent resend behavior (re-delivering existing active temp password if generated recently).
2. Frontend integration:
   - Login page "Forgot my password" link & modal (`ForgotPasswordModal`).
   - Tenant Administration / Condominium page user reset button with confirmation modal displaying the generated temporary password.

## Requirements Covered
- **PASS-01**: Login-screen "Forgot my password" flow for admins (TenantAdmin, PlatformAdmin) — temporary password delivered via SMTP email; enumeration-safe (uniform response body + constant-cost decoy verify); rate-limited (named ASP.NET Core 8 policy partitioned on normalized email + durable per-account counter)
- **PASS-04**: Delivery safety — hashed temp password + delivery state persisted; idempotent resend re-delivers same temp password; accounts never locked out in response to reset floods

## Tasks

### Task 1: Forgot Password Command & Enumeration-Safe Handler
- Location: `src/Modules/Security/ControlEasyReborn.Modules.Security.Application/Handlers/ForgotPasswordHandler.cs`
- Decoy BCrypt verify:
  - Generate a static dummy hash at startup: `PasswordHasher.Hash("DecoyDummyPassword123!")`.
  - If user is not found or is not an admin, perform `PasswordHasher.Verify("DecoyDummyPassword123!", DummyHash)` before returning the uniform response.
- If admin user found:
  - Check `PasswordResetRequests` for an existing valid temp password issued within the last 15 minutes. If found and active, reuse it (idempotent resend).
  - Otherwise, generate new unambiguous temp password, hash with work factor 11, update user password, re-arm `MustChangePassword = true`, revoke refresh tokens, and persist `PasswordResetRequest`.
  - Dispatch email asynchronously via `IEmailSender`. If delivery fails, mark `DeliveryState = Failed` without rolling back user update.
- Always return HTTP 200 with uniform DTO `ForgotPasswordResponse("If an account matches that email, instructions have been sent.")`.

### Task 2: ASP.NET Core 8 Partitioned Rate Limiter
- Location: `src/Host/ControlEasyReborn.Api/`
- Configure `AddRateLimiter`:
  - Named policy: `"forgot-password"`.
  - Partitioned on normalized email (extracted from request body or header).
  - Token bucket or sliding window (e.g. 3 attempts per 15 minutes per normalized email).

### Task 3: Login Page "Forgot Password" UI
- Location: `src/Web/ControlEasyReborn.Web/src/app/features/auth/login.page.ts`
- Add "Forgot password?" link below password input.
- Modal / drawer with email input and submit button.
- Displays uniform friendly confirmation: "If your account is registered as an administrator, an email with a temporary password has been sent."

### Task 4: Condominium & Tenant Admin User Reset UI
- Location: `src/Web/ControlEasyReborn.Web/src/app/features/administration/` and `platform/`
- Add "Reset password" action button next to users/attendants.
- Calls `POST /api/v1/security/users/{userId}/reset-password`.
- Displays modal with generated temporary password and "Copy to clipboard" button.

### Task 5: Tests
- Integration tests for `POST /api/v1/security/auth/forgot-password`:
  - Existing admin -> email queued in Mailpit / sent, 200 OK.
  - Non-existent user -> same 200 OK uniform response.
  - Rate limiting -> 429 Too Many Requests after threshold.
- Frontend component tests for login modal and reset actions.
