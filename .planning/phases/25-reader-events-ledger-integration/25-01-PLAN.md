<objective>
Wire reader-event ingestion into the platform's existing ledger machinery through a single write path. After 25 ships, a simulated reader event at a registered device creates a `Visit` + `AccessEvent` (or `RefusedScanAttempt` for unknowns) through the same `VisitorArrivalHandler` + `RecordAccessScanHandler` / `RecordRefusedScanHandler` write paths that the gatehouse panel uses — no second door into the Visits data model. Every event is persisted in `device_events` with `occurred_at`/`processed_at` separation and a `(device_id, sequence_number, external_event_id)` idempotency key, so a redelivery after disconnect is a no-op. Cross-tenant isolation holds end-to-end (tenant A's device cannot match tenant B's credentials). No new UI surface in Phase 25.

Purpose: DOOR-08..11. The reason 25 builds on top of 23/24: the simulator state from Phase 23 is reused to inject synthetic events; the device entity from Phase 24 (with its `IsActive`/`RemovedAtUtc` lifecycle) gates which devices accept events; the per-tenant key-derivation scheme from Phase 23 is reused where needed. The reason 25 ships backend-only: reader events are invisible to operators in real time — the ledger surfaces already carry the resulting Visit/AccessEvent/RefusedScanAttempt to the gatehouse panel and reports. Adding a "live event feed" page would be premature.

Output: 1 new SQL migration pair, ~14 new C# files (abstractions, contracts, handlers, validators, enums, entity, repository, services, endpoints, DI updates), 1 extension to the existing `RefusedScanFailureCode` enum (AccessControl), 2 new test files (ingestion + idempotent replay + cross-tenant), 1 OpenAPI regeneration. Zero new Angular pages — only the existing `devices-api.service.ts` extended with 2 new methods.

</objective>

      1. if (tenant.DoorIntegrationEnabled == false) return DeviceEventIngestionResult.TenantFlagOff;
      2. var device = deviceRepo.GetByIdAsync(tenantId, deviceId);
         if (device == null || device.RemovedAtUtc != null || !device.IsActive) return DeviceEventIngestionResult.DeviceInactive;
      3. var existing = eventRepo.GetByIdempotencyKeyAsync(tenantId, deviceId, payload.SequenceNumber, payload.ExternalEventId);

      7. Return the discriminated DTO.
