<objective>
Surface the condominium-level package-drop trigger in the gatehouse panel (LEDGER-04).

Purpose: The backend (`RecordManualAccessHandler.RecordPackageDropAsync`) already supports a
condominium-level drop via `SubjectId = Guid.Empty` (destination `GATEHOUSE`/`RECEPTION`), but the
UI never exposes it — `submitPackageDrop` and `selectPackageRecipient` both bail when
`recipient?.apartmentId` is falsy, so the mail-room/reception path is unreachable. This plan makes
the trigger reachable without fabricating an apartment.

Output: a nullable-apartment path in `gateway-control.service.ts` and a condominium-level trigger
in `gatehouse-panel.page.ts` (with a spec assertion) that sends `subjectId = Guid.Empty` with
`kind: 'package-drop'`.
</objective>
