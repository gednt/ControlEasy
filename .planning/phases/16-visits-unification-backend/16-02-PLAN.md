## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-02-01 | Tampering | PackageDescription/PackageCarrierCode free-text | medium | mitigate | FluentValidation length caps (500/64) and parameterized SQL via AccessEventRepository (no interpolation); content is operational data, never interpolated into authz or HTML |
| T-16-02-02 | Spoofing | DestinationApartmentId supplied by client | medium | mitigate | Handler re-resolves the apartment server-side via the resolver before recording the snapshot — a stale/forged apartment id fails resolution and the drop is refused with ProblemDetails |
| T-16-02-03 | Repudiation | Package drop actions | low | accept | PerformedByProfileId/GatehouseId stamped from JWT; audit trail exists in AccessEvents itself (append-only by schema convention) |
| T-16-02-04 | Info disclosure | Package contents in ledger rows | low | accept | Ledger is behind authz (Access.Read for reads in plan 16-03); description is intentionally operator-visible per requirement |
| T-16-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan; gate not triggered |
</threat_model>
