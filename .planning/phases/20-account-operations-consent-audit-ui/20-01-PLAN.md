<objective>
Lift the porteiro-only restriction in the administrative password reset handler and wire real SMTP delivery,
so a TenantAdmin can reset any of their own admins or porteiros (ACCNT-01) with the temporary password dispatched
by email and a delivery-state returned instead of plaintext (ACCNT-02). Add a tenant-scoped staff-list endpoint
that a TenantAdmin can reach to pick a reset target.

Purpose: The reset endpoint shipped in Phase 18 but (a) restricts TenantAdmin to Porteiro accounts only and
(b) returns the temp password inline and hardcodes deliveryState "Sent" without ever calling IEmailSender.
Both gaps must close server-side (never in the browser) before any TenantAdmin reset UI can exist.

Output: A reset handler that role-lifts admin+porteiro and SMTP-dispatches, a new ResetUserPasswordResponse shape
(no plaintext), a GET /api/v1/security/staff endpoint, and updated unit + integration tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TenantAdmin browser → Security API | Untrusted caller; must not read other tenants' staff or reset other tenants' users |
| Security API → MySQL (Users, PasswordResetRequests) | Tenant-isolated writes; SMTP dispatch is a server concern only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Information Disclosure | ResetUserPasswordHandler | mitigate | Remove plaintext temp password from ResetUserPasswordResponse; deliver via IEmailSender only (ACCNT-02) |
| T-20-02 | Elevation of Privilege | ResetUserPasswordHandler | mitigate | Keep cross-tenant guard (targetUser.TenantId != _tenantContext.TenantId → ForbiddenException 403); lift porteiro-only restriction only for same-tenant admins+porteiros (ACCNT-01) |
| T-20-03 | Information Disclosure | PasswordResetRequest delivery | mitigate | Mark Sent/Failed via MarkSent()/MarkFailed() around SendEmailAsync; never log the temp password in plaintext (structured warning logs email only) |
| T-20-04 | Information Disclosure | ListStaffHandler / GET /staff | mitigate | Derive tenantId from ITenantContext (not request body); ListByTenantAsync WHERE TenantId = @param0 — no cross-tenant staff rows |
| T-20-05 | Denial of Service | reset-password | accept | Reset flood handled by the separate forgot-password rate limiter (partitioned on email) + durable PasswordResetRequests counter; admin-initiated resets are authenticated (not anonymous) |
