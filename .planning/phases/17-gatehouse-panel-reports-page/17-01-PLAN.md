# Plan 17-01: Gatehouse Operator Panel & Navigation

## Objective
Consolidate gatehouse operator workflows into a single tabbed panel at `/gatehouse` adhering to the Shift Ledger design system. Compose QR scan, manual lookup, walk-in registration, and open visits into responsive, tablet-friendly tabs while preserving deep-link parity (`/gatehouse/qr`, `/gatehouse/manual`). Repoint dashboard "Add visit" and "Record access" buttons to the new gatehouse panel and clarify `/visits` as the administrative pre-registration register.

## Requirements Covered
- **PANEL-01**: Consolidated gatehouse operator panel at `/gatehouse` — tabs composing existing components (scan QR, manual lookup, walk-in registration, open visits list); deep-link parity with existing `/gatehouse/qr` and `/gatehouse/manual` routes; follows the Shift Ledger design system
- **PANEL-02**: `/visits` demoted to admin management/reporting (pre-registration, edit, cancel); dashboard "Add visit" and "Record access" buttons repoint to the gatehouse panel

## Tasks

### Task 1: Gatehouse Operator Panel Component & Tab Composition
- Location: `src/Web/ControlEasyReborn.Web/src/app/features/gatehouse/` (or `entry-workflow/`)
- Build a consolidated `GatehousePanelPage` with tabs:
  1. **Scan QR**: embeds the QR scanner workflow (`QrScanPage` or composed scanner component).
  2. **Manual Lookup**: embeds the manual lookup workflow (`ManualLookupPage` or composed lookup component).
  3. **Walk-in Registration**: inline walk-in form that creates a visit directly `CheckedIn` via `POST /api/v1/visits` with `CheckInNow: true`, destination apartment selector, optional QR access pass generation, and quick-feedback card.
  4. **Open Visits**: table of active on-site visits (`status: 'CheckedIn'`) with quick check-out action, search, and visit duration stamp.
- Support URL tab query/routing:
  - Default tab: QR Scan (or active tab saved in query param `?tab=qr|manual|walkin|visits`).
  - Route `/gatehouse` loads the panel.
  - Route `/gatehouse/qr` redirects or activates the QR tab.
  - Route `/gatehouse/manual` redirects or activates the Manual lookup tab.

### Task 2: Dashboard Navigation & Link Repointing
- Location: `src/Web/ControlEasyReborn.Web/src/app/features/dashboard/dashboard.page.ts`
- Repoint "Record access" button to navigate directly to `/gatehouse` (QR scan tab).
- Repoint "Add visit" button to navigate to `/gatehouse?tab=walkin` (or open the gatehouse walk-in panel).
- Ensure role-check `canUseGatehouse()` still guards access.

### Task 3: Administrative Visits Page Focus
- Location: `src/Web/ControlEasyReborn.Web/src/app/features/visits/visits.page.ts`
- Update page header and copy to clearly indicate this is the **Visit Register (Administrative)** for scheduled pre-registrations, historical lookup, cancellations, and photo management.
- Ensure "Add visit" in the admin register sets `CheckInNow: false` (pre-registration).

### Task 4: Unit Tests
- Location: `src/Web/ControlEasyReborn.Web/src/app/features/gatehouse/gatehouse-panel.page.spec.ts`
- Test tab switching, deep-link query parameter handling, walk-in registration with `CheckInNow: true`, and dashboard button repointing.
