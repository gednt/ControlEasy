# Plan 18-01: Infrastructure & Security Primitives

## Objective
Establish the foundational infrastructure and cryptographic primitives required for password management:
1. Pin BCrypt work factor explicitly to ≥ 11 in `PasswordHasher`.
2. Implement secure, unambiguous temporary password generation using `RandomNumberGenerator.GetString` excluding ambiguous characters (`0/O/o`, `1/l/I`).
3. Add `IEmailSender` abstraction, MailKit SMTP adapter, and dev Mailpit container service (SMTP 1025, UI 8025); provide no-op demo email sender when `Demo.DisableOutboundEmail: true`.
4. Create MySQL migration `15-password-reset-requests.sql` for durable reset requests and delivery state tracking (`Pending`, `Sent`, `Failed`).

## Requirements Covered
- **INFRA-01**: `IEmailSender` abstraction + MailKit SMTP adapter; Mailpit dev catch-all service in docker-compose (SMTP 1025 / UI 8025); demo mode sends nothing (`Demo.DisableOutboundEmail` no-op sender); SMTP config via environment variables
- **PASS-05**: Password hashing uses BCrypt with work factor pinned explicitly ≥ 11; temp passwords generated via `RandomNumberGenerator.GetString` with an unambiguous charset (no 0/O/o, 1/l/I)
- **PASS-04** (partial): Durable persistence schema for hashed temp password and delivery state

## Tasks

### Task 1: BCrypt Work Factor Hardening & Unambiguous Password Generator
- Location: `src/Modules/Security/ControlEasyReborn.Modules.Security.Infrastructure/Persistence/PasswordHasher.cs` and `src/Modules/Security/ControlEasyReborn.Modules.Security.Application/`
- Set work factor constant: `public const int WorkFactor = 11;`
- Update `Hash(string password)` to `BCrypt.Net.BCrypt.HashPassword(password, workFactor: WorkFactor)`.
- Create `ITempPasswordGenerator` and implementation `TempPasswordGenerator`:
  - Uses `RandomNumberGenerator.GetString(UnambiguousCharset, length)`.
  - Charset: `23456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnpqrstuvwxyz!@#$%^&*` (length ≥ 12, guaranteed symbols/numbers/letters, no ambiguous glyphs).

### Task 2: Email Infrastructure Abstraction & MailKit Adapter
- Packages in `Directory.Packages.props`: `MailKit` (4.8.0), `MimeKit` (4.8.0).
- Abstraction `IEmailSender`: `Task SendEmailAsync(string toEmail, string toName, string subject, string bodyHtml, CancellationToken ct = default);`.
- `MailKitEmailSender`:
  - Connects to SMTP host/port from configuration (`Smtp:Host`, `Smtp:Port`, `Smtp:SenderEmail`, `Smtp:SenderName`, `Smtp:Username`, `Smtp:Password`, `Smtp:EnableSsl`).
  - Supports dev/testing without credentials when running against Mailpit.
- `NoOpEmailSender`:
  - Used when `Demo:DisableOutboundEmail` is true or in testing/demo mode.
- Register conditionally in DI based on configuration.

### Task 3: Docker Compose Mailpit Service
- Location: `docker/docker-compose.yml`
- Add `mailpit` service:
  - image: `axllent/mailpit:latest`
  - ports: `1025:1025` (SMTP), `8025:8025` (Web UI)
  - traefik labels for router
- Update `api` service environment:
  - `Smtp__Host: mailpit`
  - `Smtp__Port: 1025`
  - `Smtp__SenderEmail: noreply@controleasy.com`
  - `Smtp__SenderName: ControlEasy`

### Task 4: Database Migration for PasswordResetRequests
- Location: `docker/mysql/init/15-password-reset-requests.sql` and `docker/mysql/migrations/0013-password-reset-requests.sql`
- Table `PasswordResetRequests`:
  - `Id` (CHAR(36) PRIMARY KEY)
  - `TenantId` (CHAR(36) NOT NULL)
  - `UserId` (CHAR(36) NOT NULL)
  - `NormalizedEmail` (VARCHAR(256) NOT NULL)
  - `HashedTempPassword` (VARCHAR(255) NOT NULL)
  - `DeliveryState` (VARCHAR(32) NOT NULL: 'Pending', 'Sent', 'Failed')
  - `FailureReason` (VARCHAR(512) NULL)
  - `RequestedByUserId` (CHAR(36) NULL)
  - `CreatedAtUtc` (DATETIME(6) NOT NULL)
  - `DeliveredAtUtc` (DATETIME(6) NULL)
  - `ExpiresAtUtc` (DATETIME(6) NOT NULL)
  - INDEX on `(TenantId, UserId)`
  - INDEX on `(NormalizedEmail, CreatedAtUtc)`

- Unit tests for `MailKitEmailSender` and `NoOpEmailSender`.
